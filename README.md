# Projeto Integrador: Análise Financeira e Fundamentalista - Hypera Pharma (HYPE3)

Pipeline completo de Data Science para ingestão, tratamento, modelagem relacional, estatística e visualização interativa de dados contábeis públicos extraídos da CVM.

## 🛠️ Arquitetura do Projeto
- **ETL & Ingestão:** Python, Pandas, SQLAlchemy, PostgreSQL.
- **Análise Estatística:** NumPy, Estatística Descritiva.
- **Dashboard Interativo:** Streamlit.

## ⚙️ Pré-requisitos
1. Python 3.10+ instalado.
2. PostgreSQL 18+ ativo na porta 5433.
3. Biblioteca virtual configurada (`venv`).
